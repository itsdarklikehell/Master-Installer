# Master-Installer

Provides a whiptail menu to install software or remove bloatware on a newly flashed Raspbian (or Debian derivative).

## Features

- Whiptail-based interactive menu
- Install common packages and tools
- Remove bloatware
- Configure system settings

## Installation

```bash
git clone https://github.com/itsdarklikehell/Master-Installer.git
cd Master-Installer
chmod +x Master-Installer.sh
sudo ./Master-Installer.sh
```

## Usage

Run the installer with sudo privileges. The menu will guide you through installation and removal options.

## Requirements

- Raspberry Pi running Raspbian/Debian
- `whiptail` package (`sudo apt-get install whiptail`)
